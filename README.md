# 🧩 Trello Board Clone

A modern project management web app inspired by Trello, built for teams to collaborate, manage issues, and track progress efficiently.

---

## 🚀 Features

### 🏢 Organization Management
- Create and manage organizations
- Add or remove members
- Admin control over organization settings

### 📋 Board Management
- Create multiple boards within an organization
- Each board can represent a project (Web App, Mobile App, etc.)

### 🐞 Issue Tracking
- Admins can create issues (e.g., CORS errors, bugs, feature requests)
- Issues are displayed within boards for easy tracking

### 🔄 Workflow System
- Move issues through stages:
  - 📝 Todo
  - 🚧 In Progress
  - ✅ Done
- Developers can update issue status using a simple "Next" action

### 👥 Collaboration
- Team members can work together on issues
- Clear visibility of task progress
